## 本轮修复

ChatGPT 模式的项目列表会调用官方路径 `/backend-api/gizmos/snorlax/sidebar`

VPS 直连该路径收到 OpenAI Cloudflare 403 挑战，普通用量接口只返回正常的未登录响应，因此问题位于机房出口信誉，不是项目列表界面或宿主协议

本轮加入可选的本地出口：

- 只接受 `127.0.0.1`、`localhost` 或 IPv6 回环地址
- 不允许在代理网址中保存用户名或密码
- 只代理已确认受影响的官方项目列表请求
- 不代理模型对话、文件下载、SSH 或其他 VPS 流量
- 仍调用官方网址、官方请求格式和官方响应格式

服务器运营者已经接受 Cloudflare WARP 条款，生产环境现已启用这条路线：

- 使用 Cloudflare 官方 Linux 客户端
- 使用 MASQUE 和本地代理模式
- 只监听 `127.0.0.1:40000`
- WARP 报告连接正常
- 生产服务只把官方项目列表请求送入该代理
- 模型对话、下载、SSH 和 VPS 默认路由保持不变

传输层已经通过，但业务接口还不能写成通过

未登录请求无论直连还是通过 WARP，仍收到 OpenAI Cloudflare 403 挑战
