# 2026-08-12 Trillium Note 加载与保温验收

## 这轮解决了什么

B 站打开约 613 MB 的 Trillium Note 任务时，官方 Codex 引擎每次都要重新扫描完整任务文件。浏览器只需要最近 5 轮内容，但一次重复扫描仍可能持续几十秒到两分钟

本轮保留官方界面和官方任务文件作为唯一事实来源，只在服务器进程内短期复用官方引擎已经返回的最近页面

## 缓存边界

缓存只接受同时满足以下条件的结果：

- 官方界面请求最近 5 轮完整内容
- 任务状态为“空闲”
- 单条结果不超过 8 MiB
- 请求的模型、个性、开发者指令和配置没有发生变化

以下操作会立即清除相关缓存：

- 发送或完成一轮消息
- 创建分支、压缩、归档、恢复或删除任务
- 其他会改变任务内容或运行设置的官方写操作

缓存不写成第二份完整对话数据库。服务重启后必须重新读取官方任务文件
